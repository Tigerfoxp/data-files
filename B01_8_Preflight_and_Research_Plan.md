**Дата открытия:** 25.11.2026  
**Статус:** B01.8 открыт; предварительный аудит репозитория выполнен. Полный расчёт исторических рядов B/V и статистические тесты ещё не выполнены: для них необходима пакетная копия исходных CSV в расчётной среде.

## 1. Цель этапа

Проверить на полной исторической выборке, несут ли взвешенный Market Breadth и агрегированный Volume Engine самостоятельную и добавочную прогнозную информацию относительно базовых моделей `PD` и `PDM2`.

Этап не утверждает торговую стратегию и не подбирает параметры по тестовой выборке. Результат B01.8 должен показать, какие блоки допускаются к последующей walk-forward проверке, какие остаются только диагностическими и какие следует исключить.

### 2.1. Выборочная проверка формата

У нескольких файлов M1, W1, D1 и 4H проверена структура строк. Заголовок CSV имеет вид:

`time,open,high,low,close,Volume`

Выявленные особенности:

- в индексных рядах IMOEX поле `Volume` пустое; это ожидаемо и не должно превращаться в нулевой оборот;
- месячная строка с меткой `2026-11-01` является незавершённым ноябрём и должна быть исключена из M1;
- W1 использует недельные временные метки (например, `2026-11-16`);
- временные метки 4H содержат часовой пояс, в данных встречаются смещения `+04:00` и `+03:00`; при синхронизации нужно преобразовать их в UTC;
- на проверенных примерах 4H у SBER и IMOEX совпадали метки последнего бара `2026-11-21T10:00:00+03:00`.

Это выборочная, а не полная проверка всех 144 файлов. Полное обнаружение дублей, пропусков, неотсортированных строк и качества объёма остаётся пунктом B01.8.

## 3. Зафиксированная исследовательская корзина

`LKOH,SBER,GAZP,YDEX,TATN,T,GMKN,NVTK,ROSN,X5,VTBR,SBERP,OZON,PLZL,SNGSP,SNGS,HEAD,TATNP,MOEX,MTSS,IRAO,RUAL,CBOM,CHMF,NLMK,PHOR,DOMRF,SVCB,MAGN,TRNFP,RTKM,ENPG,AFLT,BSPB,FLOT`.

Вес MDMG не распределяется на другие бумаги. Текущие индексные веса остаются фиксированными на всей истории только как приближение, поскольку point-in-time история состава и весов не предоставлена. Следовательно, даже полный исторический тест будет иметь composition/survivorship bias и не должен называться point-in-time backtest.

Минимальное покрытие для валидного значения Breadth:

- `N_valid >= 25` из 36 бумаг;
- сумма весов валидных бумаг `W_t >= 75%` полного индекса;
- синхронизация только завершённых свечей;
- отсутствующая свеча не заполняется вперёд и не считается нулевым изменением;
- если любое условие нарушено — значение Breadth равно `NA`.

## 4. Формулы, подлежащие историческому расчёту

### 4.1. Breadth

Для W1, D1 и 4H:

`WB50 = 100 * (2 * Σ(w_i * I(Close_i > EMA50_i)) / W_t - 1)`

`WB200 = 100 * (2 * Σ(w_i * I(Close_i > EMA200_i)) / W_t - 1)`

`WAD = 100 * Σ(w_i * sign(Close_i / Close_i[1] - 1)) / W_t`

Для M1 вместо EMA50/EMA200 используются EMA24/EMA48.

Фиксированный диагностический композит:

`B = 0.40 * WB_fast + 0.35 * WB_slow + 0.25 * WAD`.

Отдельно сохранить WB_fast, WB_slow и WAD: композит не должен скрывать, какой именно элемент создаёт результат.

### 4.2. Volume Engine

Для каждой акции:

`TV_i = Close_i * Volume_i`

`CLV_i = ((Close_i - Low_i) - (High_i - Close_i)) / (High_i - Low_i)`; при нулевом диапазоне CLV_i = 0.

Для корзины:

`TV35 = Σ(TV_i)`

`CLV35 = 100 * Σ(TV_i * CLV_i) / Σ(TV_i)`

Формальный относительный оборот:

`RT = TV35 / median(TV35 предыдущих n завершённых баров)`

`V = CLV35 * min(RT, 1)`

Окна n: M1=24, W1=52, D1=100, 4H=100. RT* из B01.7 остаётся только proxy и не подменяет этот расчёт. Пустой Volume — пропуск; наблюдаемый ноль сохраняется как ноль. Для контрольного сравнения отдельно рассчитать turnover-weighted Flow; он не называется CVD.

## 5. Синхронизация и прогнозные горизонты

Основной индексный ряд — IMOEX. IMOEX2 может использоваться как контрольная проверка, но не смешивается с основной выборкой.

| Профиль | Горизонт цели | Примечание |
|---|---:|---|
| M1 | 3 следующих завершённых месяца | Ноябрь 2026 исключить как незавершённый |
| W1 | 4 следующих завершённых недельных бара | Календарная торговая неделя |
| D1 | 5 следующих торговых баров | По торговым датам |
| 4H | 6 следующих баров | Только завершённые бары; время приводить к UTC |

Целевая переменная — знак forward return IMOEX на соответствующем горизонте. Последние H баров без полного будущего окна исключаются из оценки.

Для M1/W1/D1 использовать строго согласованные временные метки. Для 4H использовать последний завершённый бар акции с временем `<=` времени индексного бара, только если возраст не превышает один 4H-интервал. Никакого look-ahead и использования незакрытых свечей.

## 6. Базовые модели и сравнения

Базовые модели:

- `PD = (P + D) / 2`;
- `PDM2 = (P + D + M2) / 3`.

Формулы P, D и M2 сохраняются из B01.5.2/B01.6; параметры и правила расчёта не подбираются на тестовом отрезке.

Кандидаты для абляции:

1. B отдельно: WB_fast, WB_slow, WAD, композит B;
2. Volume отдельно: CLV35, V, turnover-weighted Flow и RT как показатель активности, но не как самостоятельный направленный сигнал;
3. `PD + B` и `PDM2 + B`;
4. `PDM2 + V`;
5. `PDM2 + B + V`.

Для первичной сопоставимости композиты с B/V использовать как равновесные диагностические средние нормированных блоков, а не как утверждённые веса MRS. Если отдельная калибровка порогов понадобится, она выполняется только на train; тестовые данные не участвуют в выборе порога.

## 7. Статистический протокол

- Хронологическое разделение: первые 70% валидных наблюдений — train, последние 30% — test.
- Для всех сравнений использовать одну и ту же common sample: бары, где доступны целевая переменная, PD, PDM2, B и Volume.
- Основные метрики: Balanced Accuracy, число тестовых наблюдений, число положительных/отрицательных исходов, направление прироста к базе и 95% доверительный интервал парной разницы.
- Дополнительно: Spearman IC между непрерывным score и будущей доходностью; доля NA и покрытие по числу бумаг/индексному весу.
- 95% интервалы и разницы оценивать парным circular block bootstrap: 1 000 повторов, длина блока `2H`, фиксированный seed, одинаковые блоки для сравниваемых моделей.
- Для семейства сравнений применить поправку Holm; отдельно маркировать exploratory results.
- Не выбирать пороги, веса или окна по test. Тестовый период после расчёта не используется повторно для настройки.
- Любая статистически положительная разница без устойчивости на walk-forward и реалистичных издержках остаётся гипотезой, а не основанием для допуска в торговые правила.

## 8. Условия допуска и критерии остановки

Breadth/Volume допускаются к следующему этапу только при выполнении всех условий:

1. достаточное число тестовых наблюдений на каждом рассматриваемом горизонте;
2. положительная добавочная ценность к базовой модели на общей тестовой выборке;
3. доверительный интервал парной разницы не указывает на отсутствие эффекта после поправки на множественные сравнения;
4. результат не объясняется несколькими экстремальными эпизодами и сохраняется при временной разбивке;
5. нет скрытого forward-fill, утечки будущих баров или недопустимого смещения синхронизации;
6. качество не разваливается при снижении покрытия/изменении порога доступных весов в заранее оговорённой sensitivity-проверке.

Если модуль повышает BA, но не улучшает IC, или эффект исчезает на walk-forward, он остаётся диагностическим. Если дополнительная информация не подтверждается, модуль исключается из MRS либо используется только для визуального контекста.
